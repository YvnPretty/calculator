# 🧮 Calculadora Premium - Yakumo Class

Una calculadora web moderna con diseño **Glassmorphism**, modo oscuro y una experiencia de usuario fluida.

![Estado del Proyecto](https://img.shields.io/badge/Estado-Completado-success?style=for-the-badge)
![Tecnologías](https://img.shields.io/badge/Tech-HTML5_|_CSS3_|_JS-blue?style=for-the-badge)

## ✨ Características

- **Diseño Glassmorphism**: Interfaz moderna con efectos de desenfoque y transparencias.
- **Micro-animaciones**: Transiciones suaves y feedback visual al interactuar con los botones.
- **Soporte de Teclado**: Manejo completo a través del teclado numérico.
- **Lógica Robusta**: Manejo de decimales, operaciones encadenadas y prevención de errores (división por cero).
- **Responsive**: Adaptable a diferentes tamaños de pantalla.

## 🚀 Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/tu-usuario/calculadora.git
   ```
2. Abre `index.html` en tu navegador preferido.

## 🛠️ Tecnologías Usadas

- **HTML5**: Estructura semántica.
- **CSS3 (Custom Properties & Grid)**: Estilizado avanzado y layouts modernos.
- **JavaScript (ES6+)**: Lógica orientada a objetos.
- **Google Fonts (Outfit)**: Tipografía premium.
